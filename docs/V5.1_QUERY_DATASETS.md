## Query Configuration

### V5.1 Query File

**Location**: `config/final_query_v5.1_wildcards_fixed.txt`

**Query Components**:

1. **MeSH Terms** (High precision):
   - Databases, Genetic
   - Databases, Protein
   - Databases, Factual
   - Databases, Nucleic Acid
   - Knowledge Bases

2. **Title Keywords** (High recall):
   - database*, repositor*, atlas, portal, consortium
   - knowledgebase, "knowledge base", resource*, platform
   - dataset, toolkit, toolbox, catalog*, catalogue*
   - collection*, browser, annotation

3. **Abstract Clause** (Critical - with wildcards!):
   - URL required: `ABSTRACT:http*`
   - Terms: database*, repositor*, resource*, collection*, catalog*, catalogue*

4. **Exclusions**:
   - Retractions, withdrawals, errata

5. **Sources**:
   - MED (PubMed)
   - PMC (PubMed Central)

### Critical Wildcard Fix

**Problem Discovered**: V5 query was missing wildcards, causing EPMC to fail matching plural forms.

**V5 (BROKEN)**:
```
ABSTRACT:(database* OR repository OR resource OR collection OR catalog*)
                              ↑           ↑          ↑
                         Missing wildcards!
```

**V5.1 (FIXED)**:
```
ABSTRACT:(database* OR repositor* OR resource* OR collection* OR catalog*)
                              ↑           ↑          ↑
                         Wildcards added!
```

**Impact**: Ensembl 2012/2021 and other papers using "resources" (plural) now captured.

**Lesson Learned**: EPMC query syntax does NOT auto-stem words! Always use wildcards.

## Data Quality & Characteristics

### Expected Precision

Based on V4 testing and V5.1 improvements:

**Estimated Precision** (bio-resource papers):
- V4 baseline: ~60-70% precision (from sampling)
- V5.1 expected: ~55-65% precision (broader capture, may include more edge cases)

**Why precision may be lower**:
- Expanded abstract terms capture more borderline cases
- "resource*" is a very common term in scientific literature
- Trade-off: Higher recall (77.3%) at cost of some precision

### Classification Required

These datasets are **UNCLASSIFIED** - they represent the broad query results before ML filtering.

**Next Steps**:
1. **ML Classification** - Separate bio-resources from general papers

   - V2 conservative: ~8% positive rate = ~20,000 papers
   - PyCaret sensitive: ~27-34% positive rate = ~69,000-87,000 papers
3. **NER Extraction** - Extract database names from positives
4. **Final Inventory** - Curated list of bio-resources

## Technical Specifications

### CSV Schema

**query_results.csv** contains these fields (from EPMC API):

**Core Identifiers**:
- `id` - PubMed ID or PMC ID
- `source` - MED (PubMed) or PMC
- `pmid` - PubMed ID (if available)
- `pmcid` - PMC ID (if available)
- `doi` - Digital Object Identifier

**Publication Metadata**:
- `title` - Paper title
- `authorString` - Author list
- `journalTitle` - Journal name
- `journalISSN` - Journal ISSN
- `pubYear` - Publication year
- `pubType` - Publication type
- `isOpenAccess` - Open access flag
- `inEPMC` - Available in Europe PMC
- `inPMC` - Available in PubMed Central
- `hasPDF` - PDF available
- `hasBook` - Is book chapter
- `citedByCount` - Citation count

**Content**:
- `abstractText` - Paper abstract (if available)
- `language` - Publication language
- `pubModel` - Publication model

**Dates**:
- `firstPublicationDate` - First publication date
- `electronicPublicationDate` - Electronic publication date
- `firstIndexDate` - First indexed in EPMC

**Additional**:
- `hasTextMinedTerms` - Text mining data available
- `hasDbCrossReferences` - Database cross-references
- `hasLabsLinks` - Links to lab resources
- `hasTMAccessionNumbers` - Accession numbers via text mining

## Usage Examples

### Load Historical Dataset

```python
import pandas as pd

# Load 2011-2021 data
df_historical = pd.read_csv('data/final_query_v5.1_2011_2021/query_results.csv',
                            low_memory=False)

print(f"Historical papers: {len(df_historical):,}")
print(f"Date range: 2011-2021")
```

### Load Recent Dataset

```python
# Load 2022-mid2025 data
df_recent = pd.read_csv('data/final_query_v5.1_2022_mid2025/query_results.csv',
                        low_memory=False)

print(f"Recent papers: {len(df_recent):,}")
print(f"Date range: 2022-mid2025")
```

### Combine Datasets

```python
# Combine both periods
df_combined = pd.concat([df_historical, df_recent], ignore_index=True)

# Remove duplicates (if any)
df_combined = df_combined.drop_duplicates(subset='id', keep='first')

print(f"Combined papers: {len(df_combined):,}")
print(f"Date range: 2011-mid2025")
```

### Filter by Year

```python
# Get papers from specific year
df_2024 = df_recent[df_recent['pubYear'] == 2024]
print(f"2024 papers: {len(df_2024):,}")

# Get papers from year range
df_2022_2023 = df_recent[df_recent['pubYear'].isin([2022, 2023])]
print(f"2022-2023 papers: {len(df_2022_2023):,}")
```

### Check Open Access

```python
# Count open access papers
oa_count = df_recent['isOpenAccess'].sum()
oa_pct = (oa_count / len(df_recent)) * 100

print(f"Open access papers: {oa_count:,} ({oa_pct:.1f}%)")
```

## Known Limitations

### Query Coverage Gaps

**10 Training Positives Not Captured**:
- Papers without V5.1 query terms in title/abstract
- Documented in `MISSING_44_POSITIVES_ANALYSIS.md`
- Require manual curation or V6 optimization

**Edge Cases**:
- Papers with generic titles and no URLs
- Clinical trials, methods papers without explicit database mention
- Papers focusing on analysis rather than resource description

### Dataset Characteristics

**Not Pre-Classified**:
- These are raw query results
- ML classification required to identify bio-resources
- Expected precision: 55-65% (needs validation)

**Metadata Completeness**:
- Not all papers have full abstracts
- Some papers missing DOI or PMC ID
- Citation counts may be outdated (snapshot in time)

**Date Coverage**:
- 2025 data only through mid-year (June 30)
- Q3-Q4 2025 requires separate query
- Historical data (pre-2011) not included
