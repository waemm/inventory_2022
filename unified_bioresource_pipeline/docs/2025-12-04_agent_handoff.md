## Contact/Context

This pipeline processes scientific papers to identify bioresource announcements. The goal is to create an inventory of bioresources (databases, tools, datasets) mentioned in literature.

Key concepts:
- **Set A:** Papers with high linguistic scores (clear resource announcements)
- **Set B:** Papers classified as introductions by SetFit ML model
- **Set C:** Union of A + B (the papers we process)
- **Primary resource:** The main bioresource being announced in each paper
- **Deduplication:** Merges papers about the same resource using URL clustering + entity matching
